# Contributing

Contributions must be original or used under a compatible license with clear
provenance. Do not submit copied product code, screenshots, proprietary prompts
or real customer conversations.

1. Open an issue describing the behavior and its official protocol source.
2. Create a focused branch and add tests.
3. Update `docs/PROVENANCE.md` and `THIRD_PARTY_NOTICES.md` when relevant.
4. Run `npm run check`.
5. Add a `Signed-off-by` line to commits to certify the Developer Certificate
   of Origin: <https://developercertificate.org/>.

By intentionally submitting a contribution without marking it "Not a
Contribution", you agree that it is provided under Apache License 2.0, subject
to any separate contributor agreement accepted by the project.
